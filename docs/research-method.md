# Методология

## Насколько надёжны сведения

Сведения в биографиях различаются по надёжности. Мы отмечаем:

- **Подтверждено** — есть документ, где это прямо сказано.
- **Вероятно** — есть косвенные доказательства.
- **Предположение** — рабочая гипотеза; такие места помечены словом «предположение».
- **Противоречие** — документы расходятся; в тексте объяснено, в чём.
- **Не установлено** — данных нет.

## Правила

1. Имена приводятся так, как они записаны в документе; варианты написания перечислены на странице человека.
2. Совпадение имени и фамилии само по себе не доказывает, что это один человек.
3. Цитаты из метрических книг и других документов прочитаны по сканам или взяты из машинного распознавания Яндекс Архива. Неуверенные прочтения и цитаты, требующие сверки со сканом, отмечены на странице каждого источника; в самих цитатах сомнительное слово помечено знаком [?], непрочитанное место — […] или [неразборчиво].
4. Даты до 1918 года — по старому стилю, если не оговорено иное.
