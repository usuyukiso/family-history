# Фамилии

Фамилии, которые носили люди из этой книги. На странице фамилии — откуда она известна, где жили её носители и кто из персон её носил: по рождению, по браку или по отчиму.

У крестьян Псковской и Тверской губерний до начала XX века фамилий обычно не было: в документах их называли по имени и отчеству, например «Иван Давыдов» — Иван, сын Давыда. Поэтому многие предки на сайте в этот список не входят.
