# Мироненко

Девичья фамилия [Марии Федоровны](P1105) (1897–1972), жены [Ивана Филипповича Винника](P1104). По дереву составителя её отец — Федор Мироненко, брат — Никифор Федорович (1913). Мироненко жили на хуторе [Винники](PLC1004) Валковского уезда **Харьковской губернии**: в исповедной росписи 1900 г. там записаны крестьянин Афанасий Павлов Мироненко и военный обыватель Федор Павлов Мироненко [A1267]; родство их с Марией Федоровной не установлено.

## Где жили

- Хутор [Винники](PLC1004), Валковский уезд **Харьковской губернии**.
- С. Украинка Харьковской области — последние годы Марии Федоровны.
