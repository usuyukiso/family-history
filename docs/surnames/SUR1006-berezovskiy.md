# Березовские

Фамилия Марии Васильевны Березовской, жены [Григория Яковлевича Писарева](P1007). Её отец — [Василий Березовский](P1084), муж [Марии Анисимовны Харламенко](P1081); у них был ещё сын, имя которого неизвестно (по заметкам составителя). Откуда происходили Березовские, неизвестно.

## Где жили

- Место рождения Марии Васильевны (1919) неизвестно; по непроверенным сведениям родственников — откуда-то из Тверской губернии.
- 1942 г. — д. Филиново Крутинского района Омской области [L1002].
