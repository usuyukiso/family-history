# Анисим Харламенко (? – ?)

Анисим Харламенко — отец [Марии Анисимовны Харламенко](P1081), дед [Марии Васильевны Березовской](P1080). Известен по сведениям составителя о его детях: у него было не меньше четырёх детей — дочери Мария, Феня и Алефтина и сын Григорий. Годы жизни, место жительства и имя его жены неизвестны.
