# Евдокия Калинина (ок. 1754 – ?)

Евдокия Калинина — жена [Ивана Данилова Винниченко](P1089), мать [Ивана Иванова](P1092). Жила, по дереву составителя, на хуторе [Винники](PLC1004) (в XIX в. — Валковский уезд **Харьковской губернии**). Откуда она родом, неизвестно.

## Краткие сведения

- **Имя в документах:** «Евдокия Калинина» — Евдокия, дочь Калины.
- **Сословие и фамилия:** сословие в имеющихся выписках не указано.
- **Родилась:** ок. 1754 г. (по ревизской сказке 1795 г., с. 513) [A1262].
- **Муж:** [Иван Данилов](P1089).
- **Дети:** Анна, Татьяна, [Иван](P1092), Мария, две Евдокии, Семен — см. страницу [мужа](P1089).
