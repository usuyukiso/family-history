# Аким Иванов Вынниченко (ок. 1825 – ?)

Аким Иванов — сын [Ивана Иванова](P1092), по дереву составителя — уроженец хутора [Винники](PLC1004) (в XIX в. — Валковский уезд **Харьковской губернии**). Отец [Иоанна Акимова](P1098), прадед [Василия Акимовича Винника](P1106).

## Краткие сведения

- **Имя в документах:** «Аким Иванов» — Аким, сын Ивана.
- **Сословие и фамилия:** сословие в имеющихся выписках не указано; фамилия Вынниченко — по дереву составителя.
- **Родился:** ок. 1825 г. (по ревизской сказке 1858 г., № 277-258) [A1265].
- **Отец:** [Иван Иванов](P1092); мать в дереве составителя не указана.
- **Жена:** [Евдокия Ерофеева](P1096), ок. 1823 г. р.
- **Дети:** Матрона (ок. 1849), Стефан (ок. 1852), [Иоанн](P1098) (ок. 1853), Михаил (ок. 1854), Яков (1855), Аким (1857) — по дереву составителя.
