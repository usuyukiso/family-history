# Евдокия Ерофеева (ок. 1823 – ?)

Евдокия Ерофеева — жена [Акима Иванова Вынниченко](P1095), мать [Иоанна Акимова](P1098). Жила, по дереву составителя, на хуторе [Винники](PLC1004) (в XIX в. — Валковский уезд **Харьковской губернии**). Откуда она родом, неизвестно.

## Краткие сведения

- **Имя в документах:** «Евдокия Ерофеева» — Евдокия, дочь Ерофея.
- **Сословие и фамилия:** сословие в имеющихся выписках не указано; в дереве составителя — Вынниченко, по мужу.
- **Родилась:** ок. 1823 г. (по ревизской сказке 1858 г., с. 1032) [A1265].
- **Муж:** [Аким Иванов](P1095).
- **Дети:** Матрона, Стефан, [Иоанн](P1098), Михаил, Яков, Аким — см. страницу [мужа](P1095).
