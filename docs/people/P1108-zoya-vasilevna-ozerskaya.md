# Зоя Васильевна Озерская, урожд. Винник (1956 – 2018)

Зоя Васильевна родилась 26 марта 1956 года в семье [Василия Акимовича](P1106) и [Полины Ивановны](P1107) Винник — по дереву составителя, в селе [Винники](PLC1004) Харьковской области (до 1917 г. — Валковский уезд **Харьковской губернии**). По обеим линиям она — потомок [Данила Астапьева Винниченко](P1085), жившего в XVIII веке: по отцу — в восьмом поколении, через его сына [Ивана](P1089), по матери — в девятом, через сына [Алексея](P1087). 3 июня 1978 года в Харькове вышла замуж, по мужу — Озерская. Умерла в Харькове 31 марта 2018 года.

Все сведения о ней — из дерева составителя; документов на сайте пока нет.
