# Мария Иванова (ок. 1850 – после 1900)

Мария Иванова — жена [Емельяна Яковлева Винника](P1112), крестьянка хутора [Винники](PLC1004) Валковского уезда **Харьковской губернии**. По мнению составителя — мать [Христины Емельяновой](P1101). Откуда она родом, неизвестно.

## Краткие сведения

- **Имя в документах:** «Мария Иванова» — Мария, дочь Ивана.
- **Сословие и фамилия:** крестьянка, по мужу; в росписи 1900 г. без фамилии, в семье Емельяна Яковлева Винника [A1267]. В дереве составителя — Винник.
- **Родилась:** ок. 1850 г.: 50 лет в 1900 г. [A1267].
- **Муж:** [Емельян Яковлев](P1112) [A1267].
- **Дети:** Михаил (ок. 1872), [Христина](P1101) (ок. 1873–1874; по мнению составителя), Настасья (ок. 1889) — см. страницу [мужа](P1112).
