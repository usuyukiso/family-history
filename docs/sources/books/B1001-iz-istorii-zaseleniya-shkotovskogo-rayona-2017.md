# 2017 Из истории заселения Шкотовского района. Документы и материалы. Владивосток (B1001)

**Полное описание:** Из истории заселения Шкотовского района: документы и материалы. — Владивосток, 2017.

Сборник архивных документов о заселении Шкотовского района Приморья переселенцами в конце XIX – начале XX в. Издатель и составители в имеющихся источниках не указаны.

Из сборника использованы публикации двух документов РГИА ДВ:

- приговор об образовании сельского общества Шевелёвка, 11 февраля 1907 г. — [A1018];
- приговор крестьян д. Шевелёвка о приёме новых членов общества, 22 мая 1913 г., с. 327–328 — [A1029].

Сведения о сборнике взяты из статей канала «Генеалогия. Переселенцы на Дальний Восток» на Дзене (https://dzen.ru/a/aG6tBOajxymP9xqx, https://dzen.ru/a/aG-fbqZ5IwWFwFUH) и из снимков страниц издания с текстами приговоров 1907 и 1913 гг., которые есть у составителя.
