# DB1000 — ОБД «Мемориал»: Давыдов Павел Иванович, 1916 г. р., запись 70002475315

**Полное описание:** Обобщённый банк данных «Мемориал» (Министерство обороны РФ) — банк данных о защитниках Отечества, погибших, умерших и пропавших без вести в период Великой Отечественной войны и послевоенный период. Запись № 70002475315. Источник записи — ЦАМО (Центральный архив Министерства обороны), картотека, шкаф 53, ящик 13. https://obd-memorial.ru/html/info.htm?id=70002475315

Учётная карточка офицера, выбывшего из армии в 1949 г.

Поля записи:

| Поле | Значение |
|---|---|
| Фамилия | Давыдов |
| Имя | Павел |
| Отчество | Иванович |
| Дата рождения/Возраст | 22.06.1916 |
| Место рождения | Псковская обл., Пушкино-Горский р-н, д. Маковица |
| Дата и место призыва | 09.07.1941 |
| Место службы | ВТ 101 сд; 198 сп 101 сд |
| Воинское звание | майор |
| Дата выбытия | 21.03.1949 |
| Название источника донесения | Центральный Архив Министерства обороны |
| Номер шкафа | 53 |
| Номер ящика | 13 |

Пояснения к прочтению:

- «ВТ 101 сд» — военный трибунал 101-й стрелковой дивизии; «198 сп 101 сд» — 198-й стрелковый полк 101-й стрелковой дивизии.
- «Дата выбытия» — дата исключения из списков армии (увольнения в запас). Это не дата смерти: в банк «Мемориал» попадают и учётные карточки офицеров, уволенных после войны.
- «Маковица» — в других источниках «Маковицы» [W1000][A1037].

Поля списаны со страницы банка данных; изображение самой карточки составитель не смотрел.
