# W1000 — «Бессмертный полк»: Давыдов Павел Иванович (страница 2014 г.)

**Полное описание:** Сайт народного движения «Бессмертный полк» (moypolk.ru), раздел «Петропавловск-Камчатский». Страница «Давыдов Павел Иванович», добавлена 26.04.2014; страницу ведёт Игорь Терентьевич Вариченко. https://www.moypolk.ru/soldier/davydov-pavel-ivanovich

Карточка ветерана с фотографией; биографии нет.

Текст страницы (основные поля):

> Давыдов Павел Иванович. 26.04.2014. Солдат.
> История солдата: Ветеран ВОВ. Регион: Камчатский край. Воинское звание: Солдат. Населенный пункт: Петропавловск-Камчатский.
> Страницу солдата ведёт: Вариченко Игорь Терентьевич.

Пояснения:

- «Солдат» в поле звания — общее слово формы сайта, а не воинское звание: по другим источникам Давыдов закончил службу майором [DB1000], а на второй странице «Бессмертного полка» назван подполковником [W1001].
