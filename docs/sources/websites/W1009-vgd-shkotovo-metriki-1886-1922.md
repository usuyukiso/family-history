# W1009 — ВГД: расшифровки метрических книг Шкотовской церкви, 1886–1922 (рождения, браки, смерти)

**Полное описание:** Форум «Всероссийское генеалогическое древо» (forum.vgd.ru), раздел 1754, три темы с расшифровками метрических книг Шкотовской церкви (Камчатская духовная консистория):

- рождения 1886–1922 гг. — https://forum.vgd.ru/1754/103250/
- браки 1886–1922 гг. — https://forum.vgd.ru/1754/103240/
- смерти 1886–1922 гг. — https://forum.vgd.ru/1754/103270/

Отдельные записи из этих тем, где названы члены семьи, вынесены на сайт как самостоятельные источники (например, [A1008], [A1009], [A1020]). Здесь описан просмотр тем целиком: составитель проверил, в какие годы в приходе появляются Шевелёвка, Почеревины и шестнадцать фамилий бывших сахалинцев из списка 1905 г. [A1016].

**Какие годы охвачены** (по датам записей в расшифровках): рождения — 1886–1910 гг.; браки — 1886–1922 гг.; смерти — 1886–1922 гг. Записи есть за каждый год этих промежутков.

## Что найдено

Почеревины (во всех вариантах написания — Почеревин, Пичеревин, Почеровин) появляются в книгах только с октября 1906 г. Шевелёвка встречается раньше — с 1903 г.:

> «4.09.1903г. (7) Иоанн - крест. д. Шевелёвки Андрей Петров Свистунов его жена Анна Никитина.»

Первые записи о бывших сахалинцах Шевелёвки — январь 1906 г.:

> «26.01.1906г. (2.02) Крест. из ссыльных д. Шевелёвки Андрея Хотынец, дочь Анна – 4 ½ г. (кори)»
>
> «24.01.1906г. (2.02) Крест. из ссыльных д. Шевелёвки Андрея Хотынец, дочь Мария – 3 ½ г. (кори)»

Когда фамилии из списка сахалинцев 1905 г. впервые встречаются в записях о жителях Шевелёвки:

| Фамилия | Первая запись | Книга |
|---|---|---|
| Хотинец (Хотынец) | 24.01.1906 | смерти |
| Корж | 4.03.1906 | смерти |
| Печенев(а) | 10.04.1906 | рождения |
| Рудзит | 4.10.1906 | браки |
| Почеревин | 4.10.1906 | браки |
| Максимов(а) | 20.11.1906 | рождения |
| Давыдок | 19.12.1907 (записан «Давидов»); как «Давыдок» — с 1909 г. | рождения |
| Беккер, Бережная | 1908 | рождения |
| Поздеев(а), Дарютин | 1909 | браки, смерти |

Жиганов, Жигулин, Лазуренко, Илюшканин и Погорелов в записях о жителях Шевелёвки не найдены. Погорелов в Шевелёвке всё же был: в 1907 г. там записан его несовершеннолетний сын Михаил с отметкой «Водворившійся отецъ умеръ» [A1019]; записи о смерти Василия Погорелова в расшифровках нет. Однофамильцы из других деревень (Корж из Кролевца, 1897–1900; Поздеева из Осиноки, 1898; Погорелый из Кневич) к сахалинцам не относятся.

Пояснения:

- Расшифровки сделаны участниками форума; сканы, по которым они выполнены, на сайте не приводятся. Отсутствие записи в расшифровке ещё не доказывает, что её нет в самой книге.
- Поиск вёлся по фамилиям во всех трёх темах; учитывались только записи, где человек назван жителем Шевелёвки.
