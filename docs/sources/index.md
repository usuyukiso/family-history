# Источники

Каждый источник — отдельная страница с постоянным идентификатором. Буква обозначает тип источника, номер не меняется и не используется повторно:

| Префикс | Тип |
|---|---|
| `A` | Архивная запись: архив, фонд, опись, дело, лист, ссылка на скан |
| `D` | Документ или цифровой файл: скан, PDF, заметки |
| `B` | Книга, опубликованное издание |
| `F` | Фотография |
| `W` | Веб-страница |
| `N` / `L` / `I` / `M` / `DB` / `V` / `O` | Газета, письмо, устное свидетельство, карта, база данных, аудио/видео, официальная публикация |
