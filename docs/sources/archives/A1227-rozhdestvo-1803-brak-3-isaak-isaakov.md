# 1803 Метрическая книга Христорождественской церкви погоста Рождество, ч. 2 (о бракосочетавшихся), № 3: брак Исаака, сына Исаака Сергеева, и Мавры Афанасьевой (A1227)

**Полное описание:** Метрическая книга: Христорождественская церковь погоста Рождество Опочецкого уезда, 1803 г., ч. 2 (о бракосочетавшихся), № 3, запись от 25 января 1803 г. Архивный шифр книги не указан; скан книги — с сайта FamilySearch (по заметкам составителя).

Брак крестьянина деревни Захарино Исаака, сына Исаака Сергеева, 17 лет, с Маврой Афанасьевой, 15 лет, из той же деревни; упомянуты Яков Павлов из д. Печохново и Настасья Сергеева из д. Брюшково.

Скан документа есть у составителя в личной коллекции (файл `1803.01.25_No.3_wedding_der.Zakh.Isaak_IsaakSergeev_17y_der.Zakh.MavraAfanasyeva_15y_upom._der.Pechoh.YakovPavlov_der.Brushk.NastasyaSergeeva.jpg`).
