# 1903 Метрическая книга Покровской церкви погоста Язвицы, ч. 2 (о бракосочетавшихся), № 2: брак Илариона Иванова из д. Глазков и Прасковьи Евграфовой из д. Глиновки (A1207)

**Полное описание:** Государственный архив Тверской области (ГАТО, ф. 160, оп. 15, д. 903): метрическая книга Покровской церкви погоста Язвицы Ржевского уезда Тверской губернии, 1903 г., ч. 2 (о бракосочетавшихся). В приход входила д. Глазки (в книгах — «деревня Глазковъ») Казинской волости. Номер листа на скане — 226. Запись № 2: брак Илариона Иванова из д. Глазков и Прасковьи Евграфовой из д. Глиновки.

Скан получен с сайта FamilySearch. Скан документа есть у составителя в личной коллекции (файл `1903.01.27_#2_wedding_der.Glaz.IlarionIvanov_19y_der.Glinovka.ParaskevaEvgrafova_upom.AndreyMakarov_der.Grom.GerasimNilov_Yazv.jpg`).
