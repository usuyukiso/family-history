# 1912 Метрическая книга Христорождественской церкви погоста Рождество, ч. 3 (об умерших): смерть Алексея, сына Иоанна Васильева (A1118)

**Полное описание:** Метрическая книга: Христорождественская церковь погоста Рождество Опочецкого уезда, 1912 г., ч. 3 (об умерших), запись от 5 июня 1912 г.. Архивный шифр книги не указан; скан книги — с сайта FamilySearch (по заметкам составителя).

Запись № 27 (мужской пол): умер 5 июня, погребён 7 июня 1912 г. «Опочецкаго уѣзда, Полянской волости, деревни Маковицъ, крестьянина Иоанна Васильева сынъ Алексей», 4 месяцев (прочтение по скану).

Скан документа есть у составителя в личной коллекции (файл `1912.06.05_death_Aleksey_IoannVas_4mon.jpg`).

**Текст:** полная расшифровка записи на сайте не приводится; выше — основная часть графы «Званіе, имя, отчество и фамилія умершаго» по скану.

## Пояснения к прочтению

- Чей это сын — Иоанна Васильева, мужа Александры Андреевой, или его тёзки, мужа Пелагеи Андреевой, — по записи не установить: в ней назван только отец, «крестьянина Иоанна Васильева», без фамилии и без имени матери.
