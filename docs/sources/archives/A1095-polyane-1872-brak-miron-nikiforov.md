# 1872 Метрическая книга Покровской церкви погоста Поляне, ч. 2 (о бракосочетавшихся), № 13: брак Мирона Никифорова, поручитель Иван Давыдов (A1095)

**Полное описание:** Метрическая книга: Покровская церковь погоста Поляне Опочецкого уезда, 1872 г., ч. 2 (о бракосочетавшихся), № 13, запись от 29 октября 1872 г.. Архивный шифр книги не указан; скан книги — с сайта FamilySearch (по заметкам составителя).

Брак Мирона Никифорова, 25 лет, из деревни Маковицы и Иродионы Макаровой, 21 года, из деревни Наушкова; поручители — Иван Давыдов и Василий Павлов из Маковиц (по прочтению составителя).
