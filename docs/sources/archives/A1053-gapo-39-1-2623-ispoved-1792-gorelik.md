# 1792 ГАПО, ф. 39, оп. 1, д. 2623: исповедные росписи церквей Опочецкого уезда, д. Горелик (A1053)

**Полное описание:** Государственный архив Псковской области (ГАПО), ф. 39, оп. 1, д. 2623. Исповедные росписи церквей Опочецкого уезда, 1792 г. Деревня [Горелик](PLC1015), двор 160 (л. 173 об.). Дворы деревни Маковицы из того же дела — [A1310].

Двор Сергея Афанасьева в Горелике: с ним сыновья Исаак и Потап с жёнами.

Исповедная роспись — ежегодный список прихожан, которые были (или не были) у исповеди и причастия; записывали по дворам, с возрастом каждого.

Скан документа есть у составителя в личной коллекции (файл `1792_ispoved_39-1-2623_GAPO_No.157_871_der.Gorelik.pdf`).

## Пояснения к прочтению

- Таблица — расшифровка составителя по скану. Графы: «Двор» — номер двора по росписи (стоит у первой строки двора); «М.» и «Ж.» — сквозные порядковые номера мужчин и женщин; «Кто» — отношение к главе двора, как записано («жена ево», «дети их»); затем имя, отчество (в старой форме: «Иванов» — Иванович) и возраст («лета»).
- Пустые клетки — в расшифровке ничего не записано. Отметки об исповеди и причастии в расшифровку не внесены.
