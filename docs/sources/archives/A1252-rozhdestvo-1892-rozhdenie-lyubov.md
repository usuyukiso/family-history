# 1892 Метрическая книга Христорождественской церкви погоста Рождество, ч. 1 (о родившихся): рождение Любови, дочери Иулиания Космина (A1252)

**Полное описание:** Метрическая книга: Христорождественская церковь погоста Рождество Опочецкого уезда, 1892 г., ч. 1 (о родившихся), запись от 13 сентября 1892 г. Архивный шифр книги не указан; скан книги — с сайта FamilySearch (по заметкам составителя).

Рождение Любови, дочери крестьянина деревни Захарино Иулиания Космина и Евдокии Николаевой; упоминается Алексей Андреев (по-видимому, крёстный).

Скан документа есть у составителя в личной коллекции (файл `1892.09.13_birth_Lyubov_YulianiyKosmin_EvdokiyaNikolaeva_upom.AlekseyAndreev.jpg`).

**Текст недоступен:** дословный текст записи на сайте не приводится; краткое содержание — по прочтению составителя (скан у составителя).
