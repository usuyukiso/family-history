# 1893 Метрическая книга Покровской церкви погоста Язвицы, ч. 3 (об умерших), № 6 (мужского пола): смерть Ивана Стефанова, д. Глазков, 39 лет (A1200)

**Полное описание:** Государственный архив Тверской области (ГАТО, ф. 160, оп. 15, д. 902): метрическая книга Покровской церкви погоста Язвицы Ржевского уезда Тверской губернии, 1893 г., ч. 3 (об умерших). В приход входила д. Глазки (в книгах — «деревня Глазковъ») Казинской волости. Номер листа на скане — 157. Запись № 6 (мужского пола): смерть Ивана Стефанова, д. Глазков, 39 лет.

Скан получен с сайта FamilySearch. Скан документа есть у составителя в личной коллекции (файл `1893.02.01_#6_death_der.Glaz.IvanStefanov_39y_Yazv.jpg`).
