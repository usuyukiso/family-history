# 1836 Метрическая книга Христорождественской церкви погоста Рождество, ч. 3 (об умерших), № 30: смерть Потапия Сергеева (A1130)

**Полное описание:** Метрическая книга: Христорождественская церковь погоста Рождество Опочецкого уезда, 1836 г., ч. 3 (об умерших), № 30, запись от 23 июня 1836 г.; лист 666 (номер скана). Архивный шифр книги не указан; скан книги — с сайта FamilySearch (по заметкам составителя).

Смерть крестьянина деревни Захарино Потапия Сергеева, 52 лет.

Скан документа есть у составителя в личной коллекции (файл `1836.06.23_#30_death_der.Zakh.PotapiySerg_52y_Rozhd.jpg`).

Текст записи (прочтение скана):

> «30. Того же числа, удельной вотчины Вороницкаго приказа деревни Захарина крестьянинъ Потапій Сергеевъ» — 52 [года].
>
> Исповедовал и приобщал приходской священник Митрофан Иванов; «Требу сію совершали: Священникъ Митрофанъ Ивановъ, Діаконъ Григорій Вознесенскій, Дьячекъ Василій Кудрявцевъ, Пономарь Матфей Мефодіевъ».

## Пояснения к прочтению

- «Того же числа» — дата предыдущей записи; по имени файла у составителя — 23 июня.
- Возраст 52 года даёт год рождения около 1784; по исповедным росписям 1774 и 1792 гг. Потап родился около 1767–1771 гг. [A1052][A1053]. Причина смерти не прочитана.
