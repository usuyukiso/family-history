# 1897 Метрическая книга Покровской церкви погоста Язвицы, ч. 2 (о бракосочетавшихся), № 2: брак Герасима Нилова из д. Громовки и Христины Ивановой из д. Глазков (A1204)

**Полное описание:** Государственный архив Тверской области (ГАТО, ф. 160, оп. 15, д. 902): метрическая книга Покровской церкви погоста Язвицы Ржевского уезда Тверской губернии, 1897 г., ч. 2 (о бракосочетавшихся). В приход входила д. Глазки (в книгах — «деревня Глазковъ») Казинской волости. Номер листа на скане — 292. Запись № 2: брак Герасима Нилова из д. Громовки и Христины Ивановой из д. Глазков.

Скан получен с сайта FamilySearch. Скан документа есть у составителя в личной коллекции (файл `1897.01.20_#2_wedding_der.Gromovki.GerasimNilov_22y_der.Glaz.HristinaIvanova_20y_Yazv.jpg`).
