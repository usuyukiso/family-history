# 1833 Метрическая книга Покровской церкви погоста Поляне, ч. 1 (о родившихся), № 14: рождение Матроны, дочери Петра Давыдова (A1073)

**Полное описание:** Метрическая книга: Покровская церковь погоста Поляне Опочецкого уезда, 1833 г., ч. 1 (о родившихся), № 14, запись от 19 марта 1833 г.. Архивный шифр книги не указан; скан книги — с сайта FamilySearch (по заметкам составителя).

Крещение Матроны, дочери Петра Давыдова и Марфы Семеновой; восприемники — Гавриил Семенов и Дарья Максимова, жена Василия Давыдова, из деревни Маковицы (по прочтению составителя).
