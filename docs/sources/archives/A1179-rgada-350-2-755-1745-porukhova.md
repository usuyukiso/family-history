# 1745 РГАДА, ф. 350, оп. 2, д. 755: переписная книга (II ревизия), д. Порухова (A1179)

**Полное описание:** Российский государственный архив древних актов (РГАДА), ф. 350, оп. 2, д. 755. Книга переписная дворовых людей пригорода Воронич, дворцовых, помещичьих, архиерейских, монастырских и церковных крестьян губ Вороничского уезда (II ревизия), 1745–1748 гг. Деревня Порухова (стр. 113 – 114 по нумерации снимков составителя).

Деревня Порухова: дворы Алексея Меркульева, детей Ивана Федорова, Фомы Терентьева, Луки Алексеева (переведён из деревни Бындина Егорьевской губы), Семена Петрова, Родиона Терентьева — 16 душ.

Вторая ревизия (перепись податного населения) 1745 г. Записаны только мужчины, с возрастом; отмечено, кто записан «в прежней переписи» (I ревизия, 1719–1722) и кто родился после неё.

Скан документа есть у составителя в личной коллекции; в его личной библиотеке расшифровка хранится как файл `1745_II_Revision_350-2-755_RGADA_all.docx`.
