# 1719 РГАДА, ф. 350, оп. 2, д. 2681: переписная книга Вороничского уезда (I ревизия), д. Алексеево Зуево (A1276)

**Полное описание:** Российский государственный архив древних актов (РГАДА), ф. 350, оп. 2, д. 2681, л. 405. Переписная книга пригорода Воронича и Вороничского уезда первой ревизии (1719 г.), дворцовая Вороницкая вотчина, Ильинская губа: запись деревни [Алексеево Зуево](PLC1007). Записаны только души мужского пола. Список всех деревень губы — [A1274].

Скан есть у составителя в личной коллекции: файл `1719_I_Revision_350-2-2681_RGADA_Voronich/350-2-2681 (0410)_der.Mihalevo404ob.JPG`, правая страница (л. 405), середина, сразу после деревни Горелик [A1275]. Следующая деревня — Проборово.

Текст (прочтение скана, сверено составителем со сканом 2026-10-21):

> Деревни Алексеево Зуево крестьянин Нестер Кононов пятидесяти лет, у него дети Козма осми лет, Понкратей четырех лет, Демид десяти лет, Антон пяти лет.
