# 1903 Метрическая книга Покровской церкви погоста Язвицы, ч. 1 (о родившихся), № 26 (женского пола): рождение Анны, дочери Димитрия Васильева, д. Глазков; восприемник — солдатский сын Яков Иванов (A1208)

**Полное описание:** Государственный архив Тверской области (ГАТО, ф. 160, оп. 15, д. 903): метрическая книга Покровской церкви погоста Язвицы Ржевского уезда Тверской губернии, 1903 г., ч. 1 (о родившихся). В приход входила д. Глазки (в книгах — «деревня Глазковъ») Казинской волости. Номер листа на скане — 222. Запись № 26 (женского пола): рождение Анны, дочери Димитрия Васильева, д. Глазков; восприемник — солдатский сын Яков Иванов.

Скан получен с сайта FamilySearch. Скан документа есть у составителя в личной коллекции (файл `1903.11.12_#26_birth_Anna_DimitriyVas_EkatGrig_upom.YakovIvanov_DariaVasilyeva_Yazv.jpg`).

Графы бланка:

1. «Счетъ родившихся: мужеска пола»;
2. «Счетъ родившихся: женска пола»;
3. «Мѣсяцъ и день: рожденія»;
4. «Мѣсяцъ и день: крещенія»;
5. «Имена родившихся»;
6. «Званіе, имя, отчество и фамилія родителей, и какого вѣроисповѣданія»;
7. «Званіе, имя, отчество и фамилія воспріемниковъ»;
8. «Кто совершалъ таинство крещенія»;
9. «Рукоприкладство свидѣтелей записи по желанію».
