# 1904 Метрическая книга Покровской церкви погоста Язвицы, ч. 2 (о бракосочетавшихся), № 7: брак Якова Иванова, солдатского сына из д. Глазков, и Феодосии Михайловой из д. Заборина (A1209)

**Полное описание:** Государственный архив Тверской области (ГАТО, ф. 160, оп. 15, д. 903): метрическая книга Покровской церкви погоста Язвицы Ржевского уезда Тверской губернии, 1904 г., ч. 2 (о бракосочетавшихся). В приход входила д. Глазки (в книгах — «деревня Глазковъ») Казинской волости. Номер листа на скане — 270. Запись № 7: брак Якова Иванова, солдатского сына из д. Глазков, и Феодосии Михайловой из д. Заборина.

Скан получен с сайта FamilySearch. Скан документа есть у составителя в личной коллекции (файл `1904.01.30_#7_wedding_der.Glazkov.YakovIvanov1_21y_der.Zaborina_FeodosiyaMihaylova1_19y_upom.VasTrofimov.jpg`).
