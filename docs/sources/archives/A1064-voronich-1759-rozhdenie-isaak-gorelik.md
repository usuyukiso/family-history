# 1759 Метрическая книга Георгиевской церкви пригорода Воронича, ч. 1 (о родившихся): рождение Исаака, сына Сергея, д. Горелик (A1064)

**Полное описание:** Метрическая книга: Георгиевская церковь пригорода Воронича, 1759 г., ч. 1 (о родившихся), запись от 29 мая 1759 г.. Архивный шифр книги не указан; скан книги — с сайта FamilySearch (по заметкам составителя).

Крещение Исаака, сына Сергея из деревни Горелик. По прочтению составителя отец записан как «Сергей Фокин»; восприемники — Малафей Григорьев и Пелагея Никифорова из деревни Печохново.

Скан документа есть у составителя в личной коллекции (файл `1759.05.29_No._birth_der.Gorelik.Isaak_SergeyFokin_upom.MalafeyGrig_upom.der.Pechoh.PelageyaNikiforova_VoronichGeorgB2.jpg`).

**Текст недоступен:** дословный текст записи на сайте не приводится; краткое содержание — по прочтению составителя (скан у составителя).

## Пояснения к прочтению

- Отчество отца «Фокин» (то есть сын Фоки) совпадает с исповедной росписью 1754 г., где отец Сергея назван Фокой (Фомой?) Феодотовым [A1048]; в ревизии 1763 г. тот же человек — Афанасий Федотов [A1049].
