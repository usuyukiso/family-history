# 1851 Метрическая книга Христорождественской церкви погоста Рождество, ч. 1 (о родившихся), № 39: рождение Екатерины, дочери Исаака Космина (A1239)

**Полное описание:** Метрическая книга: Христорождественская церковь погоста Рождество Опочецкого уезда, 1851 г., ч. 1 (о родившихся), № 39, запись от 22 ноября 1851 г. Архивный шифр книги не указан; скан книги — с сайта FamilySearch (по заметкам составителя).

Рождение Екатерины, дочери крестьянина деревни Захарино Исаака Космина и Мавры Васильевой; упомянута Дарья, дочь Космы Потапова (по-видимому, крёстная).
