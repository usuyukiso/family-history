# 1895 Метрическая книга Христорождественской церкви погоста Рождество, ч. 3 (об умерших), № 47: смерть Андрея Космина (A1141)

**Полное описание:** Метрическая книга: Христорождественская церковь погоста Рождество Опочецкого уезда, 1895 г., ч. 3 (об умерших), № 47, запись от 2 декабря 1895 г.; лист 434 (номер скана). Архивный шифр книги не указан; скан книги — с сайта FamilySearch (по заметкам составителя).

Смерть крестьянина деревни Захарино Андрея Космина, 50 лет.

Скан документа есть у составителя в личной коллекции (файл `1895.12.02_death_AndreyKosmin_50y.jpg`).

Текст записи (прочтение скана):

> «47. Декабрь 2. 4. Опочецкаго уезда, Вороницкой волости, деревни Захарина крестьянинъ Андрей Косминъ» — 50 [лет].
>
> Исповедовал и погребал «Священникъ Николай Ковалевский съ причтомъ», «на приходскомъ кладбище».

## Пояснения к прочтению

- Лист с заголовком «Метрической книги на 1895 год, часть третья, о умерших».
- Возраст 50 лет даёт год рождения около 1845; по записи о рождении он родился в 1840 г. [A1131]. Причина смерти прочитана не полностью.
