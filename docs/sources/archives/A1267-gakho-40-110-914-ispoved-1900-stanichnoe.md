# 1900 ГАХО, ф. 40, оп. 110, д. 914: исповедная роспись Предтеченской церкви с. Станичного, хутор Винники (A1267)

**Полное описание:** Государственный архив Харьковской области (ГАХО; укр. ДАХО), ф. 40, оп. 110, д. 914, л. 191–270. Исповедная роспись Предтеченской церкви села Станичного Валковского уезда Харьковской губернии за 1900 год. Хутор [Винники](PLC1004): военные обыватели — с. 198–199, крестьяне — с. 228–231. Номер страницы — как в выписке составителя.

Исповедная роспись — ежегодный список прихожан, которые были (или не были) у исповеди и причастия; записывали по дворам, с возрастом каждого.
