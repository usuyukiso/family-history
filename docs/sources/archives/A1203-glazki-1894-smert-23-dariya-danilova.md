# 1894 Метрическая книга Покровской церкви погоста Язвицы, ч. 3 (об умерших), № 23 (женского пола): смерть вдовы Дарьи Даниловой, д. Глазков, 41 год (A1203)

**Полное описание:** Государственный архив Тверской области (ГАТО, ф. 160, оп. 15, д. 902): метрическая книга Покровской церкви погоста Язвицы Ржевского уезда Тверской губернии, 1894 г., ч. 3 (об умерших). В приход входила д. Глазки (в книгах — «деревня Глазковъ») Казинской волости. Номер листа на скане — 156. Запись № 23 (женского пола): смерть вдовы Дарьи Даниловой, д. Глазков, 41 год.

Скан получен с сайта FamilySearch. Скан документа есть у составителя в личной коллекции (файл `1894.10.03_#23_death_der.Glaz.DariaDanilova_41y_Yazv.jpg`).

4. «Мѣсяцъ и день: погребенія»;
