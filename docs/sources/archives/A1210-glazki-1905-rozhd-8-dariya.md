# 1905 Метрическая книга Покровской церкви погоста Язвицы, ч. 1 (о родившихся), № 8 (женского пола): рождение Дарии, дочери солдатского сына Якова Иванова, д. Глазков (A1210)

**Полное описание:** Государственный архив Тверской области (ГАТО, ф. 160, оп. 15, д. 903): метрическая книга Покровской церкви погоста Язвицы Ржевского уезда Тверской губернии, 1905 г., ч. 1 (о родившихся). В приход входила д. Глазки (в книгах — «деревня Глазковъ») Казинской волости. Номер листа на скане — 6. Запись № 8 (женского пола): рождение Дарии, дочери солдатского сына Якова Иванова, д. Глазков.

Скан получен с сайта FamilySearch. Скан документа есть у составителя в личной коллекции (файл `1905.03.07_#8_birth_Daria_YakovIvanov_FeodosiyaMihailova_upom.DariaVasilyeva.jpg`).
