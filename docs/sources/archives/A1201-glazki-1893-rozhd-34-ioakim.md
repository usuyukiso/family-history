# 1893 Метрическая книга Покровской церкви погоста Язвицы, ч. 1 (о родившихся), № 34 (мужского пола): рождение Иоакима, сына вдовы Дарьи Даниловой, д. Глазков (A1201)

**Полное описание:** Государственный архив Тверской области (ГАТО, ф. 160, оп. 15, д. 902): метрическая книга Покровской церкви погоста Язвицы Ржевского уезда Тверской губернии, 1893 г., ч. 1 (о родившихся). В приход входила д. Глазки (в книгах — «деревня Глазковъ») Казинской волости. Номер листа на скане — 145. Запись № 34 (мужского пола): рождение Иоакима, сына вдовы Дарьи Даниловой, д. Глазков.

Скан получен с сайта FamilySearch. Скан документа есть у составителя в личной коллекции (файл `1893.08.08_#34_birth_der.Glaz.Joakim_DariaDanilova_upom.der.Glaz.IvanIvanov_HristinaIvanova_Yazv.jpg`).

Графы бланка:

1. «Счетъ родившихся: мужеска пола»;
2. «Счетъ родившихся: женска пола»;
3. «Мѣсяцъ и день: рожденія»;
4. «Мѣсяцъ и день: крещенія»;
5. «Имена родившихся»;
6. «Званіе, имя, отчество и фамилія родителей, и какого вѣроисповѣданія»;
7. «Званіе, имя, отчество и фамилія воспріемниковъ»;
8. «Кто совершалъ таинство крещенія»;
9. «Рукоприкладство свидѣтелей записи по желанію».
