# 1902 Метрическая книга Покровской церкви погоста Язвицы, ч. 1 (о родившихся), № 7 (мужского пола): рождение Григория, сына Ивана Иванова, д. Глазков (A1206)

**Полное описание:** Государственный архив Тверской области (ГАТО, ф. 160, оп. 15, д. 903): метрическая книга Покровской церкви погоста Язвицы Ржевского уезда Тверской губернии, 1902 г., ч. 1 (о родившихся). В приход входила д. Глазки (в книгах — «деревня Глазковъ») Казинской волости. Номер листа на скане — 169. Запись № 7 (мужского пола): рождение Григория, сына Ивана Иванова, д. Глазков.

Скан получен с сайта FamilySearch. Скан документа есть у составителя в личной коллекции (файл `1902.03.01_#7_birth_der.Glaz.Grigoriy_IvanIvanov_DariaSemenova_upom.der.Glaz.IlarionIvanov_Yazv.jpg`).

Графы бланка:

1. «Счетъ родившихся: мужеска пола»;
2. «Счетъ родившихся: женска пола»;
3. «Мѣсяцъ и день: рожденія»;
4. «Мѣсяцъ и день: крещенія»;
5. «Имена родившихся»;
6. «Званіе, имя, отчество и фамилія родителей, и какого вѣроисповѣданія»;
7. «Званіе, имя, отчество и фамилія воспріемниковъ»;
8. «Кто совершалъ таинство крещенія»;
9. «Рукоприкладство свидѣтелей записи по желанію».

- Месяц — по строке «Мартъ» над записью.
- «Кр-нъ», «кр-скій» — крестьянин, крестьянский.
- Крёстный Иларион Иванов — по-видимому, дядя ребёнка (брат отца); крёстная Евдокия Семенова — из той же деревни, что мать, вероятно её сестра.
