# 1911 Метрическая книга Покровской церкви погоста Язвицы, ч. 2 (о бракосочетавшихся), № 4: брак Андрея Васильева из д. Прудёнки и Вассы Ивановой из д. Глазков (A1215)

**Полное описание:** Государственный архив Тверской области (ГАТО, ф. 160, оп. 15, д. 903): метрическая книга Покровской церкви погоста Язвицы Ржевского уезда Тверской губернии, 1911 г., ч. 2 (о бракосочетавшихся). В приход входила д. Глазки (в книгах — «деревня Глазковъ») Казинской волости. Номер листа на скане — 244. Запись № 4: брак Андрея Васильева из д. Прудёнки и Вассы Ивановой из д. Глазков.

Скан получен с сайта FamilySearch. Скан документа есть у составителя в личной коллекции (файл `1911.01.26_#4_wedding_der.Prudenki.AndreyVas_29y_der.Glaz.VassaIvanova_20y_.jpg`).

4. «Лѣта жениха»;
5. «Званіе, имя, отчество, фамилія и вѣроисповѣданіе невѣсты, и которымъ бракомъ»;
