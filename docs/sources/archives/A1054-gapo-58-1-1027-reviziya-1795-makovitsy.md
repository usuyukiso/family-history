# 1795 ГАПО, ф. 58, оп. 1, д. 1027: ревизские сказки Воронецкой дворцовой вотчины (V ревизия), д. Маковицы (A1054)

**Полное описание:** Государственный архив Псковской области (ГАПО), ф. 58 (Псковская казённая палата), оп. 1, д. 1027. «Ревизские сказки о крестьянах Велейской казенной вотчины, Воронецкой дворцовой вотчины, Красногородской дворцовой вотчины Опочецкого уезда Псковского наместничества за 1795 год», л. 102. Деревня [Маковицы](PLC1002).

Семья Федота Евстафьева. Расшифрована только часть двора.

Ревизская сказка — именной список податного населения, который составляли во время ревизий (переписей) XVIII–XIX вв.

Скан документа есть у составителя в личной коллекции.

Текст (расшифровка составителя):

### Деревня Маковицы, семья Федота Евстафьева
> | Двор | Кто | Имя | Отчество | Лет |
> |---|---|---|---|---|
> |  |  | Федот | Евстафиев | 56 |
> |  | у него жена | Лукерья | Козьмина | 64 |
> |  | у них дети | Давыд |  | 39 |
> |  |  | Анна |  | 27 |
> |  | у Давыда жена | Ксения | Сафронова | 40 |

## Пояснения к прочтению

- Таблица — расшифровка составителя по скану. Графы: «Двор» — номер двора; «Кто» — отношение к главе двора, как записано; затем имя, отчество и возраст. Отчество в старой форме: «Федотов» — Федотович.
- В ревизской сказке возраст записан на год ревизии; у умерших с прошлой ревизии стоит помета «умер».
