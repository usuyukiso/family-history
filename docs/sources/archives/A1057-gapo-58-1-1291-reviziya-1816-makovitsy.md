# 1816 ГАПО, ф. 58, оп. 1, д. 1291: ревизские сказки об удельных крестьянах Опочецкого уезда (VII ревизия), д. Маковицы (A1057)

**Полное описание:** Государственный архив Псковской области (ГАПО), ф. 58, оп. 1, д. 1291. «Ревизские сказки об удельных крестьянах разных деревень Опочецкого уезда Вязовского, Велейского, Воронецкого, Покровского удельных приказов», 1816 г., л. 76–79. Деревня [Маковицы](PLC1002), двор 2.

Семья Давыда Федотова. Сказка различает его детей «от первой жены» и «от второй жены».

Ревизская сказка — именной список податного населения, который составляли во время ревизий (переписей) XVIII–XIX вв.

Скан документа есть у составителя в личной коллекции.

Текст (расшифровка составителя):

### Деревня Маковицы, двор 2
> | Двор | Кто | Имя | Отчество | Лет |
> |---|---|---|---|---|
> | 2 |  | Давыд | Федотов | 59 |
> |  | Давыдов от первой жены сын | Василий |  | 41 |
> |  | его же от второй жены сын | Петр |  | 9 |
> |  | его же от второй жены другой сын | Пимен |  | 7 |
> |  | его же от второй жены третий сын | Иван |  | 1 |
> |  | Давыда Федотова жена | Варвара |  | 37 |
> |  | Василия Давыдова жена | Авдотья |  | 45 |

## Пояснения к прочтению

- Таблица — расшифровка составителя по скану. Графы: «Двор» — номер двора; «Кто» — отношение к главе двора, как записано; затем имя, отчество и возраст. Отчество в старой форме: «Федотов» — Федотович.
- В ревизской сказке возраст записан на год ревизии; у умерших с прошлой ревизии стоит помета «умер».
