# 1780 ГАПО, ф. 39, оп. 1, д. 1617: исповедная роспись церквей пригорода Воронича, д. Попова Гора (A1164)

**Полное описание:** Государственный архив Псковской области (ГАПО), ф. 39, оп. 1, д. 1617. Исповедные росписи церквей Воскресенской, Георгиевской, Николаевской пригорода Воронича, 1780 г. Деревня Попова Гора, двор 95 (л. 14–14 об.).

Двор Филиппа Кондратьева; его внук Иван Елисеев уже женат на Агафье.

Исповедная роспись — ежегодный список прихожан, которые были (или не были) у исповеди и причастия; записывали по дворам, с возрастом каждого.
