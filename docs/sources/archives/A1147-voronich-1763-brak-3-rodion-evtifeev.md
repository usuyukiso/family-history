# 1763 Метрическая книга Георгиевской церкви пригорода Воронича, ч. 2 (о бракосочетавшихся), № 3: брак Родиона Евтифеева и Евдокии Захарьевой (A1147)

**Полное описание:** Метрическая книга: Георгиевская церковь пригорода Воронича, 1763 г., ч. 2 (о бракосочетавшихся), запись от 3 января 1763 г. Архивный шифр книги не указан; скан книги — с сайта FamilySearch (по заметкам составителя).

Венчание Родиона Евтифеева из деревни [Маковицы](PLC1002), сына Евтифея Иванова и брата Федота, с Евдокией Захарьевой из деревни Синичино.

Скан документа есть у составителя в личной коллекции (файл `1763.01.03_No._wedding_der.Mak.RodionEvtifiev_der.Sinichino.EvdZakharieva_VoronichGeorgB2.jpg`).

Текст записи (прочтение скана):

> «3. Отрок деревни Маковицы Родионъ Евтифеевъ з девицею деревни Синичино Евдокиею Захарьевою, обое они того уезду и губ и вотчин, пришествие [?] дети первымъ браком.»

Пояснения к прочтению:

- Лист с заголовком «Часть вторая бракосочетавшихся 1763 году», месяц — «Генварь», число — 3. Номер записи в этой книге не проставлен.
- «Отрок» — неженатый юноша; «первымъ браком» — оба вступали в брак впервые.
- Слово перед «дети» прочитано предположительно.
