# 1806 ГАПО, ф. 39, оп. 1, д. 2680: исповедные росписи церквей Опочецкого уезда, д. Попова Гора (A1167)

**Полное описание:** Государственный архив Псковской области (ГАПО), ф. 39, оп. 1, д. 2680. Исповедные росписи церквей города Опочки и церквей, погостов Опочецкого уезда, 1806 г. Пятницкая церковь Святогорского монастыря, деревня Попова Гора, двор 75 (л. 1139 об.).

Двор вдовца Елисея Филиппова, 89 лет: сын Иван с женой Агафьей Мокеевой, внуки Филипп и Феодор с жёнами, сын Петр с семьёй.

Исповедная роспись — ежегодный список прихожан, которые были (или не были) у исповеди и причастия; записывали по дворам, с возрастом каждого.

Скан документа есть у составителя в личной коллекции (файл `1806_ispoved_39-1-2680_GAPO_SvGoryTabol_der.PG.pdf`).
