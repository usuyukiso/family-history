# 1906 Метрическая книга Покровской церкви погоста Язвицы, ч. 1 (о родившихся), № 44 (мужского пола): рождение Иакова, сына Герасима Нилова, д. Громовка; восприемник — Яков Иванов из д. Глазков (A1212)

**Полное описание:** Государственный архив Тверской области (ГАТО, ф. 160, оп. 15, д. 903): метрическая книга Покровской церкви погоста Язвицы Ржевского уезда Тверской губернии, 1906 г., ч. 1 (о родившихся). В приход входила д. Глазки (в книгах — «деревня Глазковъ») Казинской волости. Номер листа на скане — 54. Запись № 44 (мужского пола): рождение Иакова, сына Герасима Нилова, д. Громовка; восприемник — Яков Иванов из д. Глазков.

Скан получен с сайта FamilySearch. Скан документа есть у составителя в личной коллекции (файл `1906.11.18_#44_der.Gromovka.JakovGerasimNilov_upom.der.Glazkov.JakovIvanov.jpg`).

Графы бланка:

1. «Счетъ родившихся: мужеска пола»;
2. «Счетъ родившихся: женска пола»;
3. «Мѣсяцъ и день: рожденія»;
4. «Мѣсяцъ и день: крещенія»;
5. «Имена родившихся»;
6. «Званіе, имя, отчество и фамилія родителей, и какого вѣроисповѣданія»;
7. «Званіе, имя, отчество и фамилія воспріемниковъ»;
8. «Кто совершалъ таинство крещенія»;
9. «Рукоприкладство свидѣтелей записи по желанію».
