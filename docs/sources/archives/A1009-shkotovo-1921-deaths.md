# 1921 Метрическая книга Шкотовской церкви, ч. 3 (об умерших), 17/30 июня: смерть Евдокии Почеревиной (A1009)

**Полное описание:** Архив администрации ЗАТО г. Большой Камень, ф. 113, оп. 1 (номер дела за 1921 г. в публикации не указан). Метрическая книга Шкотовской (Тихвинской) церкви, ч. 3 (об умерших), запись от 17/30 июня 1921 г.

Смерть Евдокии Почеревиной.

Текст (расшифровка; опубликована на форуме «Всероссийское генеалогическое древо», https://forum.vgd.ru/1754/103270/):
> 17/30.06.1921г. (20/3) Гражд. д. Шевелёвки Евдокия Почеровина – 70л. (старости)

Даты через косую черту — старый и новый стиль. «(20/3)» — по-видимому, день погребения: 20 июня по старому стилю, 3 июля по новому. Фонд и опись указаны по публикации расшифровки; скан неизвестен.
