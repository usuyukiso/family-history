# 1876 Метрическая книга Покровской церкви погоста Поляне, ч. 3 (об умерших), № 27: смерть младенца Феодора, сына Василия Иванова (A1098)

**Полное описание:** Метрическая книга: Покровская церковь погоста Поляне Опочецкого уезда, 1876 г., ч. 3 (об умерших), № 27, запись от 1 июля 1876 г.; лист 79. Архивный шифр книги не указан; скан книги — с сайта FamilySearch (по заметкам составителя).

Смерть младенца Феодора, сына Василия Иванова из деревни Маковицы, 3 недель.

Скан документа есть у составителя в личной коллекции (файл `1876.07.01_No.27_death_der.Mak.Feodor_VasIvanov_3ned_Polyane.jpg`).

Текст записи (прочтение скана):

> «27. Іюля 1. 3. Полянской Волости деревни Маковицъ Крестьянина Василия Иванова сынъ Младенецъ Феодоръ» — 3 недели, «отъ неизвестной болезни».
