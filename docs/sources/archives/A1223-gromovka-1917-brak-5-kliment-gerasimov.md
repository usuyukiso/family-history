# 1917 Метрическая книга Покровской церкви погоста Язвицы, ч. 2 (о бракосочетавшихся), № 5: брак Климента Герасимова из д. Громовки; поручитель — солдат Иларион Иванов Писарев из д. Глазков (A1223)

**Полное описание:** Государственный архив Тверской области (ГАТО, ф. 160, оп. 15-3, д. 3260 «Метрические книги Покровской церкви погоста Язвицы Ржевского у. Тверской губ.» (245 страниц)): метрическая книга Покровской церкви погоста Язвицы Ржевского уезда Тверской губернии, 1917 г., ч. 2 (о бракосочетавшихся). В приход входила д. [Глазки](PLC1001) (в книгах — «деревня Глазковъ») Казинской волости. Номер листа на скане — 200. Запись № 5: брак Климента Герасимова из д. Громовки; поручитель — солдат Иларион Иванов Писарев из д. Глазков.

Скан опубликован на портале Тверского архива (водяной знак archives.tverreg.ru). Скан документа есть у составителя в личной коллекции (файл `1917.11.12_#5_wedding_der.Gromovki_der.Borovtsa_upom.der.Glaz.IlarionIvanovPisarev_#1_Yazv.png`).

Графы бланка:

1. «Счетъ браковъ»;
2. «Мѣсяцъ и день»;
3. «Званіе, имя, отчество, фамилія и вѣроисповѣданіе жениха, и которымъ бракомъ»;
4. «Лѣта жениха»;
5. «Званіе, имя, отчество, фамилія и вѣроисповѣданіе невѣсты, и которымъ бракомъ»;
6. «Лѣта невѣсты»;
7. «Кто совершалъ таинство»;
8. «Кто были поручители»;
9. «Подпись свидѣтелей записи по желанію».

Пояснения к прочтению:

- Месяц — по строке «Ноябрь» над записью № 4.
- Жених Климент Герасимов из Громовки — по-видимому, сын Герасима Нилова и Христины Ивановой [A1204] (по возрасту — около 1898 г. р.).
- Это единственная запись среди имеющихся у составителя церковных записей, где фамилия «Писаревъ» написана при самом событии, а не добавлена позже.
