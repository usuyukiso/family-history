# 1747 ГАПО, ф. 39, оп. 1, д. 2510: исповедная роспись Введенской церкви Утрецкого погоста, д. Мокряне (A1152)

**Полное описание:** Государственный архив Псковской области (ГАПО), ф. 39, оп. 1, д. 2510. Исповедные росписи церквей погостов Опочецкого уезда (копия), 1747 г. Роспись Введенской церкви Утрецкого погоста Опочецкого заказа Псковской епархии, лл. 204–205; деревня [Мокряне](PLC1010), двор 14 (л. 205).

Двор Ильи Абросимова в деревне Мокряне: он сам, жена Акилина Трофимова, сын Егор, брат Никита с женой Матроной и сыном Савином.

Исповедная роспись — ежегодный список прихожан, которые были (или не были) у исповеди и причастия; записывали по дворам, с возрастом каждого.

Скан документа есть у составителя в личной коллекции (файл `1747_ispoved_39-1-2510_GAPO_pogost.Utretki_der.Mokryane14_and_villages_pp.204-210.pdf`).

Заголовок росписи (л. 204, прочтение скана): «Роспись Псковской епархии Опочецкаго заказу Утрецкаго погоста церкви Введения Пресвятыя Богородицы… 1747».

Графы бланка:

1. «Число дворов»;
2. «Число людей мужеска»;
3. «Женска»;
4. «Духовные и их домашние»;
5. «Лета возраста мужеска»;
6. «Женска»;
7. «Показание кто были у исповеди и святаго причастия»;
8. «Которые у исповеди не были».

Текст (расшифровка составителя, сверена со сканом):

### Деревня Мокряне, двор 14 (л. 205)
> | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
> |---|---|---|---|---|---|---|---|
> | 14 | 46 |  | Деревни Мокрянъ Илья Абросимовъ | 29 |  | были |  |
> |  |  | 46 | жена ево Акилина Трофимова |  | 41 | были |  |
> |  | 47 |  | у него дети Егоръ | 5 |  |  |  |
> |  | 48 |  | у него ж братъ Никита | 23 |  | были |  |
> |  |  | 47 | жена ево Матрона |  | 25 | были |  |
> |  | 49 |  | у него сынъ Савинъ | 3 |  |  |  |

Пояснения к прочтению:

- В графе 7 взрослые двора объединены фигурными скобками с пометкой, что они были у исповеди; в таблице это передано словом «были» (пометка не цитата). Маленькие дети (до 7 лет) к исповеди не ходили.
- Отчество жены Акилины читается как «Трофимова» (буквы частично размыты).
- «У него дети Егоръ» — сын Ильи Абросимова; в 1806 г. в Мокряне записан «Егоръ Ильинъ» (см. [A1154]).
- Чей помещик владел деревней, в записи этого двора не сказано.
