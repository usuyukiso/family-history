# 1799 Исповедная роспись: семьи Алексея и Ивана Даниловых Винниченко (A1263)

**Полное описание:** исповедная роспись 1799 года, с. 103, № 377-1511 (номера по выписке составителя). Церковь и архивный шифр пока не указаны.

Документ указан в заметках родословного дерева составителя (Familio).  Скан и выписки — у составителя; на сайте документ пока не расшифрован.

Исповедная роспись — ежегодный список прихожан, которые были (или не были) у исповеди и причастия; записывали по дворам, с возрастом каждого.
