# 1745 РГАДА, ф. 350, оп. 2, д. 755: переписная книга (II ревизия), д. Красихина (A1180)

**Полное описание:** Российский государственный архив древних актов (РГАДА), ф. 350, оп. 2, д. 755. Книга переписная дворовых людей пригорода Воронич, дворцовых, помещичьих, архиерейских, монастырских и церковных крестьян губ Вороничского уезда (II ревизия), 1745–1748 гг. Деревня [Красихина](PLC1012) (стр. 141 по нумерации снимков составителя).

«Новопоселенная деревня Красихина», переведённая из деревни [Горелик](PLC1015): Афанасий Федотов, 46 лет, с сыновьями Яковом, Понкратием, Исаком и Сергеем — 5 душ.

Вторая ревизия (перепись податного населения) 1745 г. Записаны только мужчины, с возрастом; отмечено, кто записан «в прежней переписи» (I ревизия, 1719–1722) и кто родился после неё.

Скан документа есть у составителя в личной коллекции; в его личной библиотеке расшифровка хранится как файл `1745_II_Revision_350-2-755_RGADA_all.docx`.
