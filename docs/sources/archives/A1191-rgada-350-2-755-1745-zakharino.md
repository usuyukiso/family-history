# 1745 РГАДА, ф. 350, оп. 2, д. 755: переписная книга (II ревизия), д. Захарино (A1191)

**Полное описание:** Российский государственный архив древних актов (РГАДА), ф. 350, оп. 2, д. 755. Книга переписная дворовых людей пригорода Воронич, дворцовых, помещичьих, архиерейских, монастырских и церковных крестьян Заклинской, Терденской, Егорьевской, Угрецкой, Полянской, Михайловской, Ильинской, Спасской и Богородицкой губ Вороничского уезда (II ревизия), 1745–1748 гг. Деревня [Захарино](PLC1003); лист в выписке не указан.

Деревня Захарино: дворы Антона Анкиндинова с братом Сидором, Герасима Филатова, Макара Федорова, Ерофея Иванова, Захара Ильина, Мартына Федорова, переведённых из деревень Ракитино и Баранова, и «явившегося из бегов» Кузьмы Ефимова.

Вторая ревизия (перепись податного населения) 1745 г. Записаны только мужчины: «голова» двора, его братья, сыновья и внуки, с возрастом; отмечено, кто переведён из другой деревни и кто умер после прошлой ревизии.

Скан документа есть у составителя в личной коллекции; в его личной библиотеке расшифровка хранится как файл `1745_II_Revision_350-2-755_RGADA.xlsx`.

## Пояснения к прочтению

- Строки без номера — пометки составителя о том, откуда переведены семьи («переведенные из Воронецкого у. Богородицкой губы д. Ракитино», «из д. Баранова», «явившийся из бегов»).
- Предков, у которых есть страницы на сайте, в Захарине 1745 г. нет: семья Сергея Афанасьева переселилась сюда позже, между 1792 и 1802 гг.
