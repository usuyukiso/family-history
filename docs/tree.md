# Родословное древо

Нажмите на стрелку, чтобы раскрыть детей, на имя — чтобы открыть страницу человека; знак 💍 — супруг. Цифра справа — сколько детей этого человека есть на сайте. Человек с известными отцом и матерью виден в обеих ветвях. В древе только персоны с отдельной страницей; остальные родственники — в их биографиях, полный список — на странице [Персоны](people/index.md).
