# Рудня-Бартоломеевская

Деревня в Гомельском уезде **Могилёвской губернии**.

## Административное деление

### До революции 1917 года

Дер. Рудня-Бартоломеевская — Полесская волость, Гомельский уезд, **Могилёвская губерния** (по заметкам составителя; источник пока не указан).

### После революции 1917 года

- сейчас — Чечерский район Гомельской области (Беларусь), по [карточке Familio](https://familio.org/settlements/63196e15-1586-42e1-85a7-cf85e81dead4) (данные 2021 г.).
