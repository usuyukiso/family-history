# Боровово

Дворцовая деревня Вороницкой вотчины (в 1870-х гг. — Опочецкий уезд **Псковской губернии**). Отсюда родом [Настасья Радионова](P1075), жена [Исаака Никифорова](P1074) из деревни [Костково](PLC1013).

## Административное деление

### До революции 1917 года

Дер. Боровово — 2-й стан, Опочецкий уезд, **Псковская губерния** (по «Спискам населённых мест» 1872–77 гг., № 7385 [B1011]).

В документах:

- «взятая тоеж вотчины старинная тогож уезду з деревни Боравова» (III ревизия 1763 г., д. Костково Спасской губы) [A1181].

Что Боравова 1763 года и Боровово из справочника 1872–77 гг. — одна деревня, считает составитель.

**1872–77 гг.** — Опочецкий уезд, 2-й стан (в шапке страницы — «Псковская губ. — IV. Уѣздъ Опочецкій. — Станъ 2») [B1011]:
