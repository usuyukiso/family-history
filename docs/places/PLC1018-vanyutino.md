# Ванютино

Дворцовая деревня Богородицкой губы Вороницкой вотчины (в 1870-х гг. — Опочецкий уезд **Псковской губернии**). Отсюда родом [Федосья Егорова](P1042), с 1751 года жена Елисея Филиппова из Поповой Горы.

## Административное деление

### До революции 1917 года

Дер. Ванютино — 2-й стан, Опочецкий уезд, **Псковская губерния** (по «Спискам населённых мест» 1872–77 гг., № 7377 [B1011]; там она записана как «Ванютино (Куялы)», отождествление составителя).

В документах:

- «Богородицкой губы деревни Ванютина» (метрическая книга Георгиевской церкви Воронича, 1751) [A1161];
- «старинной дворцовой Богородицкой губы з деревни Ванютина» (III ревизия, 1763, д. Попова Гора) [A1186];
- «В деревне Ванютине» (III ревизия, 1763; переписано начало листа) [A1187].

**1872–77 гг.** — Опочецкий уезд, 2-й стан (в шапке страницы — «Псковская губ. — IV. Уѣздъ Опочецкій. — Станъ 2») [B1011]:
