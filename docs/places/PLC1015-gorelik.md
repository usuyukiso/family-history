# Горелик

Дворцовая деревня Богородицкой губы Вороницкой вотчины. Отсюда родом [Афанасий Федотов](P1066) и его жена [Татьяна Иванова](P1067). Здесь жили их сын [Сергей Афанасьев](P1009) и [Анна Никифорова](P1010); здесь родился их сын [Потап Сергеев](P1012).

## Административное деление

### До революции 1917 года

Дер. Горелик — 2-й стан, Опочецкий уезд, Псковская губерния (по «Спискам населённых мест» 1872–77 гг. [B1011]).

**1745–1763 гг.** — Ильинская губа Воронецкого уезда, по карте составителя на сайте GeneaBits [W1007]: «Горелик»; в «Списках населённых мест» 1872–77 гг. — № 7194.

В документах:

- «д.ГОРЕЛИКИ»: дворы Потапа Федотова, детей Федота Стефанова, Антона Иванова; Андрей Сафронов «переведены из Егорьевской губы д.Железово» (II ревизия, 1745) [A1193];
- «Богородицкой губы деревни Горелика» (метрическая книга Георгиевской церкви Воронича, 1756) [A1063];
- «Деревня Горелик» (исповедные росписи 1754, 1770, 1774, 1792 гг.) [A1048][A1051][A1052][A1053];
- «В деревне Горелик… Итого в оной деревни Горелик писанные попередней переписи 16… налицо состоит 25» (III ревизия, 1763) [A1183];
- из Горелика около 1745 г. переселена в Красихину семья [Афанасия Федотова](P1066) [A1180].

**Церковный приход:** Георгиевская церковь пригорода Воронича (XVIII в.) [A1048][A1063].

**1872–77 гг.** — Опочецкий уезд, 2-й стан; раздел «По притокамъ р. Великой», подраздел «б) по р. Шести, отъ выхода ея изъ 2-го стана Новоржевскаго уѣзда до устья» [B1011]:
