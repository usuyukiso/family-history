# Печохново

Дворцовая деревня Ильинской губы Вороницкой вотчины (в 1870-х гг. — Опочецкий уезд **Псковской губернии**); приход — Георгиевская церковь пригорода Воронича (1742–1756). Здесь жили [Григорий Егоров](P1065), его сын [Никифор Григорьев](P1063) с женой [Евдокией (Авдотьей) Алексеевой](P1064); отсюда родом их дочь [Анна Никифорова](P1010), жена Сергея Афанасьева.

## Административное деление

### До революции 1917 года

Дер. Печохново — 2-й стан, Опочецкий уезд, **Псковская губерния** (по «Спискам населённых мест» 1872–77 гг., № 7146 [B1011]).

**1745–1763 гг.** — Ильинская губа Воронецкого уезда, по карте составителя на сайте GeneaBits [W1007]: «Печохнова».

В документах:

- «д.ПЕЧАХНОВО»: один двор — «голова Григорий Егоров - 51» с братьями Ермолаем и Захаром и сыновьями (II ревизия, 1745) [A1192];
- «Деревни Печахнова Григорей Егоров» (исповедная роспись Георгиевской церкви Воронича, 1742) [A1188];
- «Тоеж вотчины деревни Печохнова крестьянин Григорей Егоров» (метрическая книга той же церкви, 1747) [A1190];
- «Деревни Печохнова Никифор Григорьев» (исповедная роспись, 1754) [A1189];
- «Ильинской [?] губы деревни Печахновой» (метрическая книга Георгиевской церкви Воронича, 1756) [A1063];
- «Страница 92об В деревне Печохнова… Итого с оной деревни Печохнова писанные попрежней ревизии - 11» (III ревизия, 1763) [A1182];
- «жена з дер. Печохнова Анна Никифорова» (ревизия 1763 г. по д. Красихино) [A1049].

**Церковный приход:** Георгиевская церковь пригорода Воронича (1742–1756) [A1188][A1189][A1063].
