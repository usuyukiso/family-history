# Саблево (Шевели)

Дворцовая деревня Богородицкой губы Вороницкой вотчины (в 1870-х гг. — Опочецкий уезд **Псковской губернии**). Отсюда родом [Параскева Харитонова](P1070), жена [Филиппа Кондратьева](P1043) из деревни [Попова Гора](PLC1017).

## Административное деление

### До революции 1917 года

Дер. Саблево (Шевели) — 2-й стан, Опочецкий уезд, **Псковская губерния** (по «Спискам населённых мест» 1872–77 гг., № 7383 [B1011]).
